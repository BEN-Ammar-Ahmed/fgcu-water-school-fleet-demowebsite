Water School Fleet: what's built and what's next

A single place to track every vehicle and boat: trips, fuel, maintenance, papers, and who can see what.

  • Database with vehicles, drivers, licenses, trips, fuel, maintenance, invoices and documents. It also has the WEX fuel codes and the access roles.
  • Website where staff can search the fleet, open a vehicle, log trips, fuel and maintenance, and upload papers like insurance.
  • Maintenance alerts that show what's overdue or due soon, by date or mileage.
  • Access control: each person only sees what their level allows. Driver licenses are visible to top admins only.
  • Admin area where admins add people, change access levels and see the activity log.
  • Handoff notes for FGCU IT: hosting, setup and a go-live checklist.

Proposed next

Mockups only. The names and numbers are examples, not real fleet data.

1. Suggestions while typing

Matches appear as soon as you start typing. Forms suggest vehicles, drivers and values used before. Typos get a "Did you mean…?" fix that you click. The site never changes what you typed on its own.

2. A cleaner admin overview and a fuller log

The overview keeps only what admins check every day: alerts, the main numbers, who's online and the latest activity. The log now records sign-outs too, and edits show exactly what changed, old value to new value.
