# Development notes

Working notes from building the website, kept for the record. They describe what was planned at the time,
so some details have changed since. For how the site works **now**, read `../../README.md` (maintainer guide)
and `../reservations.md`.

| Folder | What's in it |
|---|---|
| `specs/` | Design decisions for each feature, as agreed before building it |
| `plans/` | Step-by-step build plans that followed those designs |
| `mockups/` | Clickable HTML mockups that were approved before building (open in a browser) |
