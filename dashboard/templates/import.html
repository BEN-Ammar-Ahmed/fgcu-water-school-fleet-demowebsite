Import a spreadsheet

Add many rows at once from an Excel (.xlsx) or CSV file. You'll match the columns and check every row before anything is saved. The file itself is not kept.

  1. Upload
  2. Match columns
  3. Review and save

Good to know

  • The first row with column names is used as the header. A title row above it is skipped.
  • Only the first sheet of a workbook is read. Up to 2,000 rows at a time.
  • Fuel, maintenance and trips are matched to vehicles by property tag, so add vehicles first.
  • Photos and scans of licenses are never imported. Only the license number, state and expiry date.
  • Everything is saved together, or nothing is. The import is recorded in Activity.
